# NYAX
NYAX - кастомный клиент для MAX. Главной целью проекта является шифрование и полная кастомизация с помощью _проработанной_ системы плагинов с безопасным управлением доступа плагинов к определенным частям приложения. (exteraGram учитесь.)

Клиент имеет полностью открытый исходный код (может и не очень читабельный, но я старался). Если есть предложения имеющие смысл - жду пул реквесты.

# Шифрование
Используется AES шифрование. Ключ для AES передается зашифрованным через RSA, что гарантирует безопасность.
Для маскировки шифрования (на случай, если MAX начнет блокировать за "подозрительные сообщения") зашифрованное сообщение переводится в набор русских букв со случайно расставленными пробелами. Выглядит - сомнительно. Будет тяжелее отследить - определенно.

# NYAX плагины
Плагины в NYAX клиенте это максимальная кастомизация с минимальными усилиями.

Если вы хотите установить себе плагин, вы должны знать - _после установки ЛЮБЫХ плагинов, приложение может стать потенциально небезопасным._
Я преувеличиваю, потому что большинство плагинов не смогут сделать ничего серьезного, но все же стоит опасаться и _не устанавливать плагины из сомнительных источников._

Если вы разработчик, вы можете изучить документацию ...скоро
